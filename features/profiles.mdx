Profiles give Chromex a specific role and set of behaviours for a conversation. Each profile sets a system prompt that shapes how the model answers, a context policy that controls which sources are attached by default, and a list of allowed sources the profile can draw from. Switching profiles is instant and takes effect on the next message you send.

## The `/` profile picker

Type `/` in the composer to open the profile picker. It lists all available built-in profiles. Select a profile to activate it for the current conversation. You can switch profiles mid-conversation at any time — the profile change applies from the next message onward.

<Tip>
The agentic route planner can automatically reroute your query to a better-suited profile if the current profile is a poor match. For example, a question sent in the Default profile about a YouTube video may be automatically handled by the YouTube Summarizer profile. You will see a note in the response when rerouting occurs.
</Tip>

## Profile context policies

Each profile has a **default context policy** that determines:

- Whether the current page is attached automatically when you open a tab
- Which read strategies the profile allows (`dom`, `vision`, `hybrid`, `adapter`)
- Which context sources the profile can use (`current-page`, `open-tabs`, `history`, `selection`, `image`, `file`)

The route planner respects the active profile's policy when deciding what to include in a request.

## Built-in profiles

  <Accordion title="Default">
    **ID:** `default`

    The baseline assistant with no specific system prompt. Page context is not attached automatically. All four read strategies are available. Use this profile for general questions and conversations that do not fit a specific role.

    **Allowed sources:** none (manual attachment only)
    **Allowed read strategies:** `dom`, `vision`, `hybrid`, `adapter`

    A YouTube research and learning copilot. Uses transcript, chapter markers, title, description, and current playback timestamp when available. Produces a one-sentence thesis, key points, timestamped moments, practical takeaways, and follow-up questions. Prefers the YouTube adapter or DOM transcript before relying on vision.

    **Allowed sources:** `current-page`, `open-tabs`, `selection`, `image`, `file`
    **Preferred actions:** summarize video, summarize current timestamp, draft blog post
    **Adapter hints:** YouTube
  </Accordion>

## Profile rerouting

If the route planner determines that a different profile is a significantly better fit for your query, it may automatically switch to that profile for the turn. This happens transparently — a note appears in the response explaining which profile handled the request. Your selected profile is not permanently changed; it reverts to your choice on the next message.

To disable automatic rerouting, keep a non-default profile selected. The planner only rereroutes away from the `default` profile when a specialist is clearly better suited.
