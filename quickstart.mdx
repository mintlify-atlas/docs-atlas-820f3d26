The fastest way to install Chromex is to download the pre-built zip from the latest GitHub Release, load it in Chrome Developer mode, and follow the onboarding flow to connect to your local Codex app-server. No build tools required.

<Note>
  Chromex requires a local Codex app-server running on your machine. The app-server handles authentication and model access. Start it before you open Chromex for the first time.
</Note>

## Install Chromex

<Steps>
  <Step title="Open the latest release">
    Go to [https://github.com/GENEXIS-AI/chromex/releases/latest](https://github.com/GENEXIS-AI/chromex/releases/latest) to find the most recent release.
  </Step>
  <Step title="Download the extension zip">
    Under **Assets**, download `chromex-unpacked-extension.zip`. This is the ready-to-install package — you do not need the source archive.
  </Step>
  <Step title="Unzip the file">
    Extract the zip. You should see a folder named `chromex-extension` containing the unpacked extension files.
  </Step>
  <Step title="Open Chrome extensions">
    In Chrome, navigate to `chrome://extensions`.
  </Step>
  <Step title="Enable Developer mode">
    Toggle **Developer mode** on using the switch in the top-right corner of the extensions page.
  </Step>
  <Step title="Load the unpacked extension">
    Click **Load unpacked** and select the `chromex-extension` folder you extracted in step 3.

    Chromex appears in your extensions list. Chrome may prompt you to pin it to the toolbar.
  </Step>
  <Step title="Open Chromex">
    Click the Chromex icon in the Chrome toolbar, or open the side panel from the browser's **Side panel** button. Chromex opens as a persistent panel on the right side of your browser window.
  </Step>
  <Step title="Connect to Codex">
    Follow the onboarding flow inside Chromex to connect to your local Codex app-server. Sign in through the app-server-backed login flow — your credentials stay on your machine.
  </Step>
</Steps>

## What to do after installing

Once Chromex is connected to Codex, you're ready to use it from any tab.

### Open the side panel

Click the Chromex toolbar icon to toggle the side panel open or closed. The panel stays open as you navigate between tabs.

### Pick a profile

Type `/` in the chat input to open the profile picker. Profiles are specialized modes that tune Chromex's behavior for a specific task — YouTube Summarizer, Research Assistant, Slide Maker, and 20 total built-in profiles to choose from.

### Mention a tab

Type `@` in the chat input to open the tab picker. Select one or more open tabs to include their content as context in your message.

### Attach a file

Click the attachment icon in the chat input to upload an image, PDF, Word document, spreadsheet, or plain text file. Chromex reads the file into the conversation.

<Tip>
  You can combine context sources in a single message — for example, mention two tabs with `@` and attach a PDF, then ask Chromex to compare them.
</Tip>
